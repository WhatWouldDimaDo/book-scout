# Security Policy

## Supported version

Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting flow](https://github.com/WhatWouldDimaDo/book-scout/security/advisories/new). Do not disclose a vulnerability, credential, personal reading data, or proof-of-concept exploit in a public issue.

Include the affected route or component, impact, reproduction steps, and a minimal proof of concept that contains no real credentials or personal data. If private reporting is unavailable, contact the repository owner through the [WhatWouldDimaDo GitHub profile](https://github.com/WhatWouldDimaDo) before sharing sensitive details.
